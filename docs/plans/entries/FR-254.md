  WHAT THIS ENTRY GOT WRONG: "valid iff B has no `continue` bound to this loop" is
  INCOMPLETE. Splicing S (or R2's C) after B's statements captures any name B declares at

  disabled: g4(17) = 4175 vs 1385); the rule now keeps `{ B }` nested when S / C names

  Guards that refuse, located at the loop: a `continue` bound to the loop (found through
  `switch`, not through nested loops or lambdas), a `for` condition variable.

  value in place and a separate prefix `++x;` follows; `return E;` becomes

  `normalize: incdec ...` census needle: the root is a local or `*p` (else "operand"); the
  site is not under `&&` / `||` / `?:` / `,` ("conditional"); the statement calls no closure

  be a scalar ("return type"). The lead's suspected hazard in `a[(*p)++] = f()` is NOT one:
