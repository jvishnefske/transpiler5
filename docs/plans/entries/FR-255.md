- [ ] FR-255 (opened 2026-11-01, child of FR-249): **BC.HPP -- A COMPILE-TIME BORROW
  DISCIPLINE FOR C++20 THAT MAPS 1:1 ONTO RUST BORROWS.** Header-only. Three language facts
  do the work: (1) every lambda expression has a unique type, so `template<class T, auto
  Brand = []{}> class Owner` gives each Owner DECLARATION its own type -- object identity
  becomes type identity; (2) a captureless lambda cannot odr-use enclosing locals, so a
  borrow callback cannot reach any Owner it was not handed; (3) a borrow lives exactly as
  long as `bc::with(borrows..., callback)` runs and the callback's result must be
  borrow-free. `bc::with(a, bc::ref(b), [](auto& x, const auto& y){..})` <=> `{ let x =
  &mut a; let y = &b; .. }`, which makes it the natural C++ spelling of borrows for the
  bijection (FR-252) and a target for the normalizer (FR-254).
  PROTOTYPE MEASURED 2026-11-01 (Clang 21.1.8, -std=c++20): positive program composing
  Owner<vector<int>>, Owner<pair<Owner<Point>, string>> (nested owners) and clone() compiles
  and runs; REJECTED AT COMPILE TIME with the intended static_assert/diagnostic: mut+ref of
  the same Owner; a capturing callback; touching another local Owner inside a borrow
  (language rule: implicit capture in a captureless lambda); returning &x from a borrow;
  Owner<int*>; copying an Owner; two elements of std::vector<Owner<int>> borrowed together
  (same type => conservatively rejected, like Rust indexing -- needs a runtime-checked
  split helper). FINDING: each written-out `bc::Owner<X>` is a NEW type, so a nested owner
  type must be named once via `using`. Composition of existing types: arithmetic, enum,
  std::string/vector/optional/array/pair/tuple built in; user aggregates opt in with
  BC_BORROW_FREE(Type, field types...) (C++20 has no reflection).
  KNOWN UNSOUNDNESS (must be documented, not hidden): inside one borrow T& is plain C++
  (iterator invalidation within one container is not caught -- wrap finer-grained parts in
  their own Owners); static/global Owners are reachable from a captureless callback; a
  callback can stash &x in a global by side effect; use-after-std::move of an Owner is left
  to clang-tidy bugprone-use-after-move.
  ACCEPTANCE: header in tools/emitrust-bx/include/bc.hpp; lit tests for the positive
  program (run + output) and every compile-fail case (`not clang++ ... 2>&1 | FileCheck`
  on the diagnostic text); a split-index helper; emitrust-bx imports `bc::with` calls as
  Kernel borrow nodes <=> Rust borrows, byte-diffed both directions. Expected TRACTOR: +0.
