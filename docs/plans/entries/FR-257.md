  **LANDED 2026-11-01 (scope 1-3; destructors stay a residual).** Canonical rows:
  - Every struct is `#[derive(Clone)] struct` with `pub` fields, NEVER Copy: a copy is
    `.clone()` and a bare variable is a move for every type, as in FR-251. Input
    `#[derive(Clone, Copy)]` is refused.
  - Aggregate init `S s = {a, b};` / `S{a, b}` <=> `S { f: a, g: b }`, every field in
    declaration order. Rust evaluates field initializers in WRITTEN order, so a reordered
    Rust literal is refused rather than reordered.
  - Methods are `impl S` with `pub fn`: const <=> `&self`, non-const <=> `&mut self`,
    static <=> associated fn, `this->f` <=> `self.f`, `*this` <=> `self.clone()`.
    Out-of-line C++ definitions; inside member functions every free call is `::`-qualified
    because a member could hide it.
  - A ctor whose body is a member-initializer list of EVERY field <=> `pub fn new(..) -> S`;
    `S(a,b)`, `S{a,b}`, `S s(a,b)` and `= {a,b}` all map to `S::new`. Other ctors,
    destructors, private members, inheritance, virtual and operators are located residuals.
  - Anonymous-namespace struct <=> private `struct` in the `mod`.
  - Normal form N15: struct definitions in topological order over by-value containment.
  - Receiver aliasing is probed against rustc 1.98.1 (not 1.96). Accepted:
    `s.set(s.get())`, `p.inner.set(p.inner.get())`, `self.set(self.x+1)`. Located
    residuals: `v[0].set(v[0].get())`, `v[0].set(v.len())`, `s.absorb(&s)`,
    `s.set(bump(&mut s))`, and `a.f() + a.f()` with a non-const f (C++ order unspecified).
