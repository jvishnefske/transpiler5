how it works

An MLIR pipeline, not a pattern matcher.

Syntax-directed translators cannot answer “what can this pointer name?”, so they fall back to raw pointers. emitrust lowers C through a real compiler middle-end and makes ownership a decision, taken with the whole translation unit in view.

01 clang AST The real C and C++ front end. No custom parser to disagree with your compiler.
02 import Types, places and effects become MLIR. Anything it cannot model is refused here, with a location.
03 planning Storage bases, borrow shapes and co-access clusters. This is where pointers stop being pointers.
04 lift Control flow becomes structured Rust; mutable globals become owned state.
05 emit A crate with a Cargo.toml, renamed to Rust convention so it passes the standard lints.

what you get

Output that survives review.

The test is not “does it compile”. It is whether a Rust engineer who has never seen the C would accept the file in a pull request.

borrows

Pointers become slices

A pointer parameter is lowered to a borrow or a slice once the analysis proves which object it names. Where it cannot prove it, you get a diagnostic — never a silent raw pointer.

ownership

Globals get an owner

Mutable file-scope state is clustered by co-access and lifted into a struct owned by main. The functions that touch it become &mut self methods. Nothing becomes static mut.

concurrency

Then it can be a thread

Because the state is genuinely owned, the runtime shape becomes a flag. The same actor can be lifted onto a thread or a task behind a mailbox, with effect order preserved.

naming

Idiomatic by default

Functions and fields to snake_case, types to UpperCamelCase, constants to SCREAMING_SNAKE_CASE — so the crate is clean under the standard naming lints on the first build.

proof

Compiling clean proves nothing.

A miscompile builds perfectly. So the load-bearing test is not the Rust compiler — it is running both binaries and comparing their bytes.

what that caught

printf("%c") on a byte ≥ 0x80 emitted two bytes, not one — Display for char writes UTF-8. 256 native bytes vs 384 emitted.

Unary minus on a float emitted as 0.0 - x, losing the sign of zero and flipping NaN's sign bit.

Statements before a break ran after a loop-local's destructor. Refused rather than reordered.

Every one of these compiled without a single warning.

limits

What it will refuse to do.

The rule is that a construct it cannot model correctly must never be emitted wrongly. Refusal is a feature, and these are the edges you will actually hit.

A subset of C, not all of C

setjmp/longjmp, most of the standard library, and constructs with no faithful Rust image are refused with a file:line:col diagnostic. --recover turns a refusal into a typed stub so the rest still builds.

Aliasing it cannot disprove

Two pointers into one object, or a pointer argument that aliases its receiver, are rejected rather than given &mut borrows that Rust would reject anyway — or worse, accept unsoundly.

One translation unit at a time

Multi-file projects go through a link step over per-TU shards. It works, but whole-program ownership across that boundary is more conservative than within one file.

Known divergences are written down

long double maps to f64. For code that does real 80-bit arithmetic that is observable, and it is recorded as a divergence rather than hidden.
